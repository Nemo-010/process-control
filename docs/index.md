lead: Applications with their processes folded beneath them, live graphs of the machine, and signals one click away. It starts at once and never freezes while the machine is busy.
screenshot: /screenshot.png
features:
  - title: Applications, not just processes
    body: A program's window names its process and its window class, and its helpers fold away underneath it. It works whatever the program was packaged as.
  - title: Quick when it matters
    body: The process table is read on a thread of its own and only the rows on screen are drawn, so the window stays responsive exactly when the machine is not.
  - title: The whole machine at a glance
    body: CPU per core, memory, GPU, network and storage, each with its history, and every one of them broken down per process and per application.
  - title: Act on what you find
    body: Terminate, force stop, or send any signal, and open a process to see its command line, memory, I/O, open files and window class.
  - title: Portable on Linux
    body: The onelf build is a single file that carries its own libraries and runs on any distribution.
